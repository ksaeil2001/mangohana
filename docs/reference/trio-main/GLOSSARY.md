# Trio 데스크톱

만화 페이지의 원문을 인식하고 번역·원문 제거·식자 결과를 검토하고 수정하는 작업 도구다. 아래 용어는 화면 배치와 관계없이 같은 뜻으로 사용한다.

## Language

**프로젝트**:
함께 작업하는 만화 페이지, 대사, 등장인물·용어와 편집 내용을 묶은 작업 단위다.

**페이지**:
프로젝트 안에서 탐색하고 처리하는 만화 이미지 한 장이다.

**대사**:
페이지에 속하는 번역·편집의 텍스트 단위다. 말풍선의 발화뿐 아니라 독백과 내레이션도 포함한다.

**일괄 처리**:
선택한 여러 페이지에 설정된 인식·번역·이미지 작업을 이어서 수행하는 작업 방식이다.

**검수**:
원문과 처리 결과를 확인하고 필요한 부분을 수정하는 사용자 작업이다. 자동 처리의 성공 여부와 구분한다.

**검수 항목**:
인식한 원문이나 번역 적용 등에 확인할 점이 있어 검수 대상으로 모은 대사다. 목록에 없다는 사실만으로 그 페이지의 모든 품질을 확인한 것은 아니다.

**검수 확정**:
선택한 대사의 검토를 마쳤다고 사용자가 명시적으로 표시하는 행동이다. 수정 내용을 저장하거나 다른 대사로 이동하는 행동과 구분한다.

**최종 읽기**:
문제 항목을 검수한 뒤 전체 페이지를 순서대로 읽으며 번역과 이미지 결과를 확인하는 작업이다. 확인 필요 항목이 없다는 상태와 구분한다.

**처리 완료**:
선택한 자동 작업이 결과를 만든 상태다. 사용자의 검수 완료나 전체 프로젝트 완성과 구분한다.

**AI 제안**:
문자 인식·화자·번역에 대해 AI가 제시한 검토 대상 값이다. 사용자가 직접 수정하거나 확정한 값과 구분한다.

**사용자 확정**:
사용자가 명시적으로 확인한 원문·번역 값의 상태다. AI가 값을 생성했다는 사실만으로 사용자 확정이 되지는 않는다.
