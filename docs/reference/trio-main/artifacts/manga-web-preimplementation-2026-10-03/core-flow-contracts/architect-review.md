# 공통 편집·출력 계약의 architect 독립 검토

검토일: 2026-10-03. 검토 담당: 기존 `/root/state_contract_review`. 담당이 architect 역할을 명시한 응답과 완료 상태를 확인했다. 파일 수정·구현·재위임 없이 읽기 전용으로 검토했다.

## 1. 최초 검토 범위와 판단

입력은 준비 명세, Domain Story 3~24절과 기존 C/K의 관련 계약이다. 범위는 업로드·수동 편집/Undo·최종 ZIP·30일 결과 라이브러리의 공통 경계와 사용자 미선택 분기다. 공식 보안 자료·29개 강의 전사·선택 runtime·제품 실행·G01~G08 전체 상세 설계는 이번 검토 범위가 아니다.

| 범위 | 검토에서 공통 계약으로 인정한 내용 | 미선택으로 남길 내용 |
| --- | --- | --- |
| 업로드 | 현재 접근/형식/내용 검증, 원본 불변, 전송/반영 확정 구분, 같은 명령 중복 방지, 내용 hash와 페이지 계보 분리 | 일부 실패의 묶음 처리, 초기 순서, 명시 중복 업로드, 지원 형식·한도 |
| 수동 편집·Undo | 네 가지 직접 수정 항목, 권한/잠금/버전 검사, 수동 이력만 Undo, 새 수정 뒤 Redo 폐기, 현재 맥락 이력·파일 미포함 | AI 성공 뒤 유효 이력 범위, 페이지/전체 Undo 단위, 인계 뒤 이용 범위 |
| ZIP | 제외 미포함·스킵 현재 결과·무수정 미번역 원본, 일관된 포함/순서/결과/자산 캡처, AI 재실행과 생성/전달 분리 | 처리 중 캡처/대기, 생성 뒤 추가 편집, 일부 렌더 실패, 출력 형식·품질·자료량 |
| 라이브러리 | 마지막 실제 자동 보관 성공 기준, 실패/조회/다운로드/정산으로 기한 연장 없음, 편집 재개 없음, 30일 뒤 삭제와 서비스 재다운로드 불가 | 갱신 단위, 보관 실패의 재처리/안내, 만료 직전 시작한 전송 |

다음 네 지적을 받았다.

1. 전체 흐름 표만으로 상세 계약 완료라 할 수 없다. 각 행동의 명령 정체성, 예상 버전, 서비스 확인, 확정 기록, 실패 뒤 조회 대상을 작성해야 한다. G03/G04 전체 완료로 표시하지 않는다.
2. 30일 뒤 삭제를 접근 만료로 축소하지 않는다. 결과 객체·복제본·캐시·다운로드 권한의 삭제/차단 범위와 검증 항목이 필요하다. 내부 대조 기록 보존은 이미지 제공 유지의 근거가 아니다.
3. 과거 수동 Undo가 새 AI 결과를 덮는 우회 복원이 되지 않게 공통 금지 경계를 명시한다. 유효 이력의 보존·무효화 단위는 사용자 미선택으로 남긴다.
4. 기존 담당의 이번 독립 검토 성공을 상태 문구에 반영하되, 공통 네 흐름의 검토로 한정한다. 이전 신규 호출의 한도 실패나 전체 설계 미완료 사실을 지우지 않는다.

검토는 Q23~Q25 응답 전 상태를 유지하며, 위 제품 분기를 추천값으로 결정하지 말라고 판단했다.

## 2. 최초 지적의 반영

[준비 명세](../../../docs/superpowers/specs/2026-10-03-manga-web-preimplementation-readiness.md) 9~10절에 공통 요청/응답·CF01~CF09·OB01~OB09·FX01~FX20을 추가했다. 30일 실제 삭제와 접근 차단을 구분하고, 과거 Undo로 새 AI 결과를 덮지 않는 경계를 명시했다. 검증 사례는 모두 NOT RUN이며 endpoint/type/schema·제품 구현은 채택하지 않았다.

[진행 계획](../../../docs/superpowers/plans/2026-10-02-manga-web-workspace-contracts-and-validation-plan.md) PRE06/PRE08 및 9.1절과 [Domain Story](../../../docs/manga-translation-domain-story.md) 59~59.3절에 부분 독립 검토와 미선택 분기의 상태를 연결했다. 기존 확정 정책은 바꾸지 않았다.

## 3. 반영본의 후속 독립 검토

동일 담당이 준비 명세 9~10절 및 상태, 진행 계획 PRE06/PRE08·9.1절, Domain Story 59~59.3절과 이 기록을 후속 검토했다. 이번 제한 범위에서 추가 필수 수정이 없으며, 공통 계약의 반영 검토를 완료로 기록할 수 있다고 판정했다. [최종 응답](architect-final-response.md)과 [범위별 상태](review-status.json)를 보존한다.

반영본은 명령/권한/버전/확정·실패 조회, 접근 차단과 실제 삭제의 구분, 로컬 파일/살아 있는 맥락 자산 경계, Undo의 우회 복원 금지를 포함한다. ZIP 재처리의 비용 표현은 AI/무료 사용·이미 정산한 비용의 반복 방지이며 실제 비용이 언제나 없다는 신규 보장이 아니다. 미선택 OB/Q와 전체 준비 미완료도 유지했다.

메인 에이전트는 후속 상태 문구에서 G03의 공통 계약 작성 사실과 G03/G04의 전체 미완료 표현만 명확히 했다. 변경은 [문구 수정 기록](review-corrections.json)에 한정한다. 업무 행동/선택의 변경이나 추가 필수 수정은 아니다.

**완료 범위는 공통 네 흐름과 미결정 분기 대조에 한정한다.** G01~G08 전체 준비, 선택 storage의 실제 삭제 가능성, 실제 제품 구현/실행 검증은 미완료다. 문서 검증은 별도 결과 파일 `document-checks.json`에 기록한다.
