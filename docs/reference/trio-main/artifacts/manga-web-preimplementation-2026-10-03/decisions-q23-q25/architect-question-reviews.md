# 선택 질문의 architect 독립 검토

일자: 2026-10-03. 담당: 기존 `/root/state_contract_review`, architect 역할. 이번 파일은 실제 받은 회신의 요약이며 원자료/제품 실행 재검증은 아니다.

## Q20·Q26·Q27

판정: 질문 진행 가능. 기존 범위/로그인/기기 선택을 재질문하는 묶음이 아니다.

- Q23-A는 지정된 내부 앱 테스트 계정이다. 외부 AI 공급사 무료 테스트 계정과 구분하고 수단별 무료 할당·일반 가입 개방으로 확대하지 않는다.
- Q27-A는 현재/새 수단 접근 증명·명시적 의도·이미 다른 계정에 연결된 수단 거부·확인 불명 보류가 필요하다. 동일 수단의 단일 계정 연결/동시성은 상세 기술 계약의 검증 과제다.
- Auth 자동 identity 연결을 명시적 앱 계정 연결의 대체로 쓰지 않는다. 실제 적합성과 자동 연결 비활성화·양방향 수단 추가는 미검증이며 Supabase 채택을 선언하지 않는다.
- Q26은 이메일 방식만 정한다. 세션 수명·상실 복구·연결 해제는 미정이다.

## Q21·Q22·Q28

판정: 전개를 막는 필수 지적 없음, 질문 진행 가능.

- 기존 이미지 묶음 전체 흐름은 모든 크기/형식/긴 웹툰의 무제한 지원을 뜻하지 않는다. Q28은 첫 지원/평가 자료 범위를 좁히는 결정이며 실제 지원 PASS가 아니다.
- 픽셀·용량·자료량·품질은 측정 뒤 판정한다. 내부 분할로 사용자 페이지나 무료 사용 단위를 만들지 않는다.
- Q21/Q22의 로컬 파일 검증 근거 수명과 라이브러리 30일을 구분한다. 실제 포맷·언어·브라우저·기간/키 운영은 미선정이다.

## Q29·Q30·Q31

판정: Q31 한도 경계를 분명히 하면 발송 가능. 지적을 반영한 뒤 세 질문을 실제 발송했다.

- Q31은 파일별 손상/형식/크기 검증 실패로 한정했다. 총 파일 수·합계 용량·프로젝트 수용량 초과에서 임의로 일부를 반영하는 정책을 함께 정하지 않는다.
- 성공분의 동일 명령 재전송과 실패분 새 업로드를 구분한다. 최초 정렬·실패분 삽입 위치·명시적 중복 처리까지 선택으로 확대하지 않는다.
- Q29-A는 첫 범위이며 다른 원문 언어는 후속이다. 전체 목표를 한국어 고정으로 바꾸지 않는다.
- Q30은 누적 범위(A, A+iPad, B+Mac)로 설명한다. 지원 선택과 실제 기기 검증은 별개다.

세 회신은 질문안/현재 정책의 정합성 검토다. 그 회신만으로 아홉 선택의 문서 반영·전체 준비·실제 인증/DB/파일/브라우저/AI가 검증됐다고 하지 않는다. 수정 문서의 최종 검토는 별도 기록한다.
