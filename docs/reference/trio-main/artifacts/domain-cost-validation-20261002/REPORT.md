**계산 예시:** 입력 2,000 + 청구 대상 출력 3,000토큰이면 Gemini 2.5 Flash 번역 API 원가는 $0.0081이다. 같은 요청을 세 번 유료 실행하면 $0.0243이다. 출력 3,000은 가령 답변 1,000 + 생각 2,000을 합친 값이다. 이는 가정한 토큰량의 산술이며 실제 만화 한 페이지 평균·최댓값·품질 검증이 아니다. 원가 기반 과금은 보이는 번역문 길이만 세면 안 된다.

탐지·OCR·인페인팅·식자·저장·전송·공통 서버비의 실제 단가는 아직 없다. 실행 환경을 선택하고 작업량·시간·메모리·보관량 등을 측정해야 한다. 전용 컴퓨팅은 준비·유휴 시간도 비용이 될 수 있다는 공개 사례가 있으나, 이를 이 서비스의 확정 원가로 가져오지는 않는다. [Replicate 과금 설명](https://replicate.com/docs/topics/billing)

## 2. 판매 상품과 수수료

2,500 / 6,000 / 15,000크레딧의 **USD 판매가격은 미정**이다. 아래 $5 / $10 / $20은 수수료 영향을 보기 위한 가정이며 상품 가격 제안이나 사용자 선택이 아니다.

Polar 신규 Starter는 거래당 **5% + $0.50**, 미국 외 카드 추가 **1.5%**다. 비율 수수료의 기준 금액에는 징수한 세금도 포함된다. 과거 **4% + $0.40**은 2026-05-27 이전 조직이 해당 Early Member 조건을 유지할 때의 요율이다. 기존 거래 수수료는 환불 시 돌려받지 못하며 분쟁 수수료는 별도다. [공식 수수료](https://polar.sh/docs/merchant-of-record/fees)

| 크레딧 | 가정한 세전 판매가 | 결제 수수료 차감 후 금액 | 크레딧당 순수입 |
| ---: | ---: | ---: | ---: |
| 2,500 | $5 | $4.1425 | $0.001657 |
| 6,000 | $10 | $8.785 | 약 $0.00146417 |
| 15,000 | $20 | $18.07 | 약 $0.00120467 |

계산 조건은 Starter·미국 외 카드·가정한 세율 10%이며, 세금은 운영자 수입에서 제외했다. 실제 거래의 센트 단위 반올림, 정산·환전·환불·분쟁·계정별 비용은 아직 차감하지 않았다. **10%는 확정 세율이 아니다.**

정산에는 지급 발생 월 $2, 지급당 0.25% + $0.25, 통화 전환 시 지역에 따른 비용이 별도로 있다. EU 외 통화 전환 비용은 최대 1%로 안내된다. KRW 지급 최소액은 USD 환산 $40로 표시된다. 한국은 지원 국가지만 계정 승인·실제 정산 가능 여부는 확인하지 않았다. USD 상품 결제가 USD 은행 입금을 보장하지도 않는다. [정산 수수료](https://polar.sh/docs/features/finance/payouts), [정산 계좌](https://polar.sh/docs/features/finance/payout-accounts), [지원 국가](https://polar.sh/docs/merchant-of-record/supported-countries)

유료 Pro 전환은 매출 총액만으로 결정하기 어렵다. 세금 없는 거래 기준 Starter 대비 주문당 절감액은 `판매가 × 1.2% + $0.10`이며 월 요금 $20을 넘겨야 이익이다. $10 주문 100건이면 $2 절감, $100 주문 10건이면 $7 손해라는 산술 결과다. 거래량·평균 결제금액·세금 등을 확인한 뒤 요금제를 비교해야 한다.

**환산 검토 결과:** 상품별·할인별·이미 판매한 미사용 크레딧까지 크레딧당 순수입이 달라질 수 있다. 현재의 가장 비싼 상품 가격만으로 환산하면 과거 할인 크레딧에서 손실이 날 수 있다. 목표 수익률과 공통비 배분은 아직 정하지 않았다. 수수료를 순수입에서 이미 차감했다면 처리 원가에 다시 더하지 않도록 계산 경계를 정해야 한다. 검증에 사용한 올림과 목표 이익률 30% 예시는 정책이 아니다. 무료 체험 비용은 기존 결정대로 운영자 부담이며 유료 사용자에게 자동 배분하지 않는다.

## 3. 자동 확인 가능 여부와 운영 기준 후보

첫 공개 HTTP 조회에서 공식 가격 문서 5곳이 응답했다. 당시 모델·통화 표식만 확인했다. 후속 7.3절에서는 Gemini Flash-Lite의 표준 무료·유료 단가를 실제 HTML에서 추출하고 모호한 표를 거부하는 연구용 검증까지 진행했다. **모든 공급사·조건의 추출과 실제 변경 적용 운영은 미검증**이다. 문서 구조 변경, 적용 시점, 과금 모드·단위·문맥 구간, 모델 별칭 변경까지 확인해야 한다.

사용자가 선택한 2-A를 구체화하기 위한 **검토 후보**는 다음과 같다. 아직 사용자 확정값이 아니다.

| 상황 | 검토 후보 |
| --- | --- |
| 일반 수집 | 공식 자료를 6시간마다 수집·비교하고 변경된 해당 요율을 검증 |
| 확인 실패 | 마지막 정상 확인 후 24시간 초과 또는 단위·모델·통화·유효 시점 검증 실패 시 해당 신규 비용 단계 보류 |
| 예상하지 못한 큰 변화 | 같은 조건의 단가가 20% 이상 바뀌면 운영 검토. 손실 위험·상한 미확인은 변화율과 무관하게 보류 |
| 공지된 시간대·문맥 구간·프로모션 종료 | 공지된 조건으로 적용하고 요청 상한을 다시 확인. 예정된 두 배 변화 자체를 자료 이상으로 취급하지 않음 |
| 재개 | 유효한 가격 자료와 전체 비용 상한을 다시 확인한 뒤 다음 비용 발생 단계부터 적용 |

이 주기가 가격의 최신성이나 잔액 초과 방지를 수학적으로 보장하지는 않는다. 공급사 가격이 조회 사이에 바뀔 수 있고 문서 갱신과 청구 적용 시점이 다를 수 있다. 유효 시점·가격 변동 여유·자료 계약까지 확인해야 3-A의 상한 판단에 사용할 수 있다. 이 보고서는 주기적 작업을 실제로 예약하거나 운영 기준을 적용한 결과가 아니다.

## 4. 모델별 실행 한도의 통제 가능성

| 공급사·요청 경로 | 공식 자료에서 확인한 것 | 실제 검증 상태 |
| --- | --- | --- |
| OpenAI Responses | `max_output_tokens`는 답변·추론 등 출력 생성 한도. `output_tokens`에 추론이 포함되어 중복 합산 금지. 한도에서 미완성이어도 생성 비용 발생 | 문서 확인. OpenAI 요청·청구 대조 NOT RUN. [추론](https://developers.openai.com/api/docs/guides/reasoning), [입력 토큰 계산](https://developers.openai.com/api/docs/guides/token-counting) |
| Gemini Interactions | `generation_config.max_output_tokens`는 생각+답변의 강제 생성 한도. 생각 중 도달하면 미완성·빈 답변도 가능. `store`·`stream`은 최상위 필드 | 문서·fixture 확인 후 실제 시도 HTTP 404. 한도 작동은 미검증. [생각·한도](https://ai.google.dev/gemini-api/docs/thinking), [API 스키마](https://ai.google.dev/api/interactions-api-v1) |
| Gemini generateContent | camelCase 설정·사용량 필드 사용. Gemini 3 이후는 `thinkingLevel`을 사용하며 이전 모델에 보내면 오류. 답변·생각 토큰을 구분해야 함 | `gemini-3.5-flash-lite`의 첫 6건·후속 12건에서 생각+답변 합계가 설정 한도 이내임을 관측. endpoint 자체의 모든 요청 보증으로 확대하지 않음. [API](https://ai.google.dev/api/generate-content) |
| Grok | 추론 비용과 한도 필드를 제공하며 모델·endpoint별 확인 필요 | OpenAI 호환만으로 생각 포함 상한을 확정하지 않음. 실제 호출 NOT RUN. [추론](https://docs.x.ai/developers/model-capabilities/text/reasoning), [Responses API](https://docs.x.ai/developers/rest-api-reference/inference/responses) |
| DeepSeek | 생성 한도와 길이 종료 사유를 제공. `medium`·`high`는 모두 실제 high로 대응 | 현재 스키마 확인, 실제 생성·생각 포함 한도·청구 대조 NOT RUN. [Chat API](https://api-docs.deepseek.com/api/create-chat-completion/) |

Gemini 관련 공개 지원 답변에서도 한도 문제를 요청 필드 위치와 함께 설명한다. 제보나 지원 답변을 이 테스트의 실행 결과로 취급하지 않는다. 실제 보낸 body의 제어 필드·응답 사용량·종료 상태를 함께 남겨야 한다. [공식 지원 포럼의 요청 형식 설명](https://discuss.ai.google.dev/t/interactions-api-output-tokens-exceed-max-output-tokens-1500/182722)

3-A를 만족하려면 입력량·청구 대상 전체 생성량·재시도 횟수·다른 호출·번역 외 처리비와 **동시에 시작한 요청이 공유하는 실행 여력**을 함께 통제해야 한다. 로컬 계산에서는 각각 $0.70인 두 요청이 $1 잔액을 독립적으로 확인하면 합계 $1.40이 되는 사례를 확인했다. 이것은 동시 처리 제어 필요성의 산술이며 예약 구조·DB 설계·선차감 정책을 확정한 것이 아니다.

현재 Trio 데스크톱의 `src/main/translation/adapters/geminiAdapter.ts`는 온도 설정과 최대 3회 시도 경로를 사용하며 이 조사에서 출력 한도·생각 설정·청구 사용량 기록을 확인하지 못했다. 이 사실은 계획 중인 웹 서비스의 구현 상태를 뜻하지 않는다. 조사용 프로브를 작성한 사실도 제품에 3-A가 구현됐다는 증거가 아니다.

## 5. Gemini 실제 실행과 계정·예산 확인

사용자는 **Gemini 테스트 계정·총 $1 이내** 실행을 허용했고 키 준비 완료를 알렸다. 실제 Windows 사용자 환경변수에서 키를 읽어 테스트 프로세스에 전달했다. AI Studio의 마스킹된 키 표시와 대조한 결과 해당 프로젝트는 무료 등급이었다. 키 값·계정 이메일·프로젝트 ID·생성한 대사는 보고서와 응답 기록에 남기지 않았다.

키 준비는 [Google AI Studio](https://aistudio.google.com/) 로그인 → Dashboard / API Keys → Create API key → 테스트 프로젝트 선택 순서다. 처음 이용하면 약관 동의 후 기본 프로젝트와 키가 생길 수 있다. Windows 사용자 환경변수 `GEMINI_API_KEY`로 저장한 뒤 준비 여부만 전달한다. 공식 안내상 신규 키는 auth key로 생성된다. [키 생성·Windows 설정](https://ai.google.dev/gemini-api/docs/api-key)

무료 등급으로 먼저 생성 한도·사용량을 시험할 수 있다. **신규 유료 전환은 보통 최소 $5 선충전이 필요**하므로 총 $1 승인만으로 선결제를 진행하지 않는다. 무료 등급 실행을 유료 청구 검증이라고 표현하지 않는다. 공급사 선불 잔액도 청구 처리 지연 중 초과 사용 가능성이 있어 요청별 한도를 대신하지 못한다. [공식 결제 안내](https://ai.google.dev/gemini-api/docs/billing)

처음 시도한 `gemini-2.5-flash` Interactions와 `gemini-2.5-flash-lite` generateContent는 각각 첫 생성 요청에서 HTTP 404를 반환했다. 모델 목록과 metadata 조회의 성공만으로 실제 생성 지원을 판단할 수 없었다. 두 실패 기록을 보존하고 각각 중단했다. 이후 입력을 비운 검증 요청은 400 / INVALID_ARGUMENT을 반환해 일반 생성 경로의 입력 검증을 확인했다. GET으로 Interactions 경로를 조회한 결과만으로 POST 지원 여부를 확정하지 않는다.

실패 요청의 미확인 비용은 처음에 보수적인 예산으로 유지했다. 테스트 키의 무료 등급과 두 모델의 공식 무료 요율을 확인한 뒤 별도 [예산 대조 기록](budget-reconciliation-free-tier-20261002.json)으로 보류 금액을 해제했다. 원래 실패 응답 기록은 수정하지 않았다. 이 대조는 유료 청구서 정산이 아니다.

후속 실행은 별도 연구 모델 `gemini-3.5-flash-lite`에 `thinkingLevel`을 명시한 generateContent 요청 5건이다. 모델·endpoint를 바꾼 사실을 기록하며 Interactions 성공으로 취급하지 않는다. 실제 만화·사용자 대사는 보내지 않았으며 자동 재시도도 하지 않았다.

| --- | ---: | ---: | ---: | ---: | --- | ---: |
| Low, 아주 작은 한도 | 24 | 4 | 0 | 8 | MAX_TOKENS | 0.0000172 |
| Low, 번역 4줄 | 89 | 58 | 0 | 1,024 | STOP | 0.0001717 |
| Medium, 같은 입력 | 89 | 58 | 0 | 1,024 | STOP | 0.0001717 |

5건 모두 HTTP 200이며 답변+생각 합계는 요청 한도를 넘지 않았다. High는 1,020토큰과 가시 텍스트 69문자를 반환하고 길이 제한으로 끝났다. 응답 텍스트를 저장하거나 번역의 정확성·완전성을 평가하지 않았으므로 이를 정상 번역 완료로 확정하지 않는다. Low와 Medium의 사용량이 같았고 High는 생각 토큰이 많았다. 이 한 번의 결과를 고정 수준 배율이나 평균 페이지 비용으로 사용하지 않는다.

High의 길이 종료를 확인한 뒤 **같은 입력·High 수준을 유지하고 한도만 8,192로 넓힌 요청을 한 번 추가**했다. 이 요청은 답변 58 + 생각 1,341 = 생성 1,399토큰, `STOP`, 가시 텍스트 97문자·비어 있지 않은 4줄을 반환했다. 형식과 정상 종료를 확인한 것이며 번역의 정확성은 평가하지 않았다. 8,192를 서비스의 확정 한도·최소 필요량으로 선택한 것도 아니다. [High 후속 응답](gemini-live-20261002T052527Z-6a5e6f3d.json)

첫 5건의 유료 요율 추정치는 $0.0031090, 후속은 $0.0035242이며 **6건 합계는 $0.0066332**다. 25% 여유를 포함한 예산 기록 합계는 **$0.008291500**으로 승인한 $1 안이다. 실제 실행 프로젝트는 무료 등급이었다. 유료 거래·청구서·정산 대조는 **NOT RUN**이다. 처음 5건에는 정확한 제공 모델 버전 필드를 보존하지 않았고, 후속 응답은 `modelVersion=gemini-3.5-flash-lite`를 기록했다. [처음 5개 응답](gemini-live-20261002T051406Z-30b403c5.json), [응답·계산 대조 요약](live-summary.json)

예산 가드는 모델 metadata의 전체 입력 한도와 출력 한도의 두 배에 해당하는 요율, 25% 여유를 이용하여 요청별 보수적 금액을 먼저 확보한다. 이전 실행에서 미확인된 금액도 합산하고 요청 전에 기록한다. 이것은 모델 최대치에 대한 문서 가정을 둔 연구용 제한이며 제공자의 절대 청구 보증이나 제품 잔액 보호 구현은 아니다. 테스트에서 관측한 한도 역시 모든 입력·모델·endpoint에서의 보증이 아니다.

## 7. 무료 등급을 유지한 페이지 검증과 후속 판단

사용자는 AI Studio 무료 등급을 유지하고 유료로 바꾸지 않겠다고 밝혔다. 이번 조사는 이 조건을 적용했으며 결제 연결·충전·유료 전환을 하지 않았다. 후속 답변으로 **현재 테스트 계정만 무료로 유지하고 출시 방식은 추후 선택**하는 안을 확정했다. 출시 공급사·계정·요금 방식은 실제 공정·원가 자료를 확인한 뒤 별도로 정한다.

### 7.1 계정·자료·요청 범위

2026-10-02 06:23 UTC에 마스킹된 키 표시와 실행 환경의 키가 유일하게 일치하는지 확인했고 해당 프로젝트의 Free 표시를 관측했다. 화면의 Flash-Lite 한도는 15 RPM / 입력 250,000 TPM / 500 RPD였다. 이는 해당 프로젝트의 관측이며 모든 무료 계정의 보장 한도가 아니다. 28일 최고 사용량 표시는 남은 한도가 아니며 공급사 한도는 프로젝트 단위다. 서비스가 신규 사용자에게 주는 무료 처리 10회분과도 별개다. [계정 관측](free-page-study/free-tier-observation.json), [공식 요청 한도](https://ai.google.dev/gemini-api/docs/rate-limits)

원본 만화나 사용자 대사를 보내지 않았다. 허구 일본어 대사를 직접 작성하고 가로쓰기 4개, 가로쓰기 12개, 세로쓰기 8개 말풍선의 1,200 × 1,600 PNG를 만들었다. 읽기 쉬운 단일 글꼴과 말풍선 식별자가 있는 인공 페이지이므로 실제 만화의 글꼴·배경·효과음·흐림·잘린 글자·후리가나 분포를 대표하지 않는다. [페이지·원문·해시 명세](free-page-study/fixture-manifest.json), [생성 스크립트](page_fixtures.py)

Gemini 이미지 OCR은 페이지별 Low 1회씩, 번역은 페이지별 Low / Medium / High 1회씩 실행했다. 번역에는 OCR 결과 대신 정답 원문을 넣어 번역 자체를 비교했다. 따라서 OCR → 번역 → 인페인팅 → 식자까지 이어진 실행 결과는 아니다. 생성 한도 8,192, 후보 1개, JSON 응답, 도구·재시도·모델 대체 없이 실행했다. 8,192는 연구 설정이며 서비스의 확정 한도가 아니다. [실행 스크립트](page_probe_gemini.py), [추가 12건 실제 응답](free-page-study/gemini-page-20261002T062607Z-f9635152.json)

### 7.2 Gemini 사용량·품질·비용 비교

12건 모두 HTTP 200 / `STOP`, 보고된 모델 버전 `gemini-3.5-flash-lite`, 생각+답변 합계 ≤ 8,192를 관측했다. 모든 식별자가 유지됐고 번역은 비어 있지 않은 한국어를 반환했다. 이미지 OCR 3건은 대사에서 공백·문장부호를 제외한 314문자 비교에서 오류 0이었다. 이는 이 인공 자료에서의 비교 결과이며 실제 만화 정확도 100%를 뜻하지 않는다.

AI가 번역 72개 문장을 원문과 검토한 범위에서는 명백한 의미 누락·반전을 찾지 못했다. 관용구를 풀어 쓰거나 직역하는 차이와 띄어쓰기·표현 차이는 있었으며 전문 번역가 검수·사용자 승인·품질 보증은 아니다. 이번 Low / Medium / High 비교로 고정 품질 순위나 비용 배율을 정하지 않는다.

### 7.3 무료 단가와 갱신 예외·동시 요청 검증

실제 공식 HTML에서 `gemini-3.5-flash-lite` / Standard / USD / 100만 토큰 / 입력·생각 포함 출력의 단일 가격표를 찾아 무료 0과 유료 0.30 / 2.50을 추출했다. 연구용 검증 28개는 단위 변경·중복 표·미지원 표기·자료 오류를 0원으로 취급하지 않고 보류하는 사례, 무료 0 → 0의 변화율 계산, 0 → 유료의 별도 검토, 공지된 변화와 예외의 구분을 포함했다. HTML 계약이 바뀌면 안전하게 보류할 수 있어야 하며 안정적인 공급사 가격 API나 장기간 갱신 서비스는 확인하지 않았다. [검증 결과](free-page-study/free-policy-results.json), [검증 스크립트](free_policy_checks.py)

또한 잔액 100·요청 상한 30인 동시 요청 10개가 공유 여력을 확인하는 연구 사례에서 3개만 시작 가능하고 합계 상한은 90이었다. 실행 여력 확인과 사후 실제 비용 정산을 구분했으며 선차감이나 사전 예상 크레딧 표시를 도입하지 않았다. 다른 처리 단계의 상한이 없으면 시작을 보류하는 사례도 확인했다. 이는 격리된 연구용 동시 실행 시뮬레이션이며 제품 DB·장애 복구·웹 서비스 잔액 보호 구현의 증거가 아니다.

6시간 수집·24시간 초과 보류·20% 이상 변경 검토는 여전히 후보다. 무료 요율도 오래됐거나 모호하면 유효한 0원으로 확정할 수 없다는 근거를 추가한 것이며 사용자에게 숫자 선택을 대신한 것은 아니다.

### 7.4 기존 로컬 OCR의 실제 실행과 품질 제한

기존 Main의 production OCR 서비스와 설치된 서명 리소스 팩을 사용했다. 설치·모델 다운로드 없이 원래 서명·체크섬·runtime probe를 통과했고 관련 생성 JS 23개 모듈이 현재 TypeScript 소스에서 나온 코드와 일치함을 확인했다. 앱 상태는 OS 임시 폴더로 격리하고 기존 프로젝트·설정·원본 자산을 사용하지 않았다. 현재 Trio의 실행 경로를 연구 대상으로 쓴 것이며 계획 중인 웹 서비스에 이 구성이나 사용자 승인 흐름을 채택한 것은 아니다.

로컬 OCR의 외부 API 비용은 $0이지만 컴퓨팅 금액은 **미정**이다. 전기·호스팅·준비·유휴 시간·공통비를 0원으로 넣지 않는다. 전체 페이지 원가는 근거 파일에서도 `null`로 남겼다.

### 7.5 후속 사용자 선택과 현재 업무 방향

사용자는 **현재 테스트 계정만 무료로 유지하고 출시 방식은 추후 선택**, **이유를 알리고 대기 후 같은 설정으로 재개**를 선택했다. 두 질문은 더 이상 답변 대기 항목이 아니다. 선택 이력과 현재 업무 이야기는 [도메인 스토리 51.2·51.3절](../../docs/manga-translation-domain-story.md)에 반영했다.

| 선택한 주제 | 사용자 확정 방향 |
| --- | --- |
| 무료 유지의 범위 | 현재 테스트 계정만 무료 유지. 출시 공급사·계정·요금 방식은 실제 자료를 보고 추후 선택 |
| 공급사 한도로 첫 처리를 시작할 수 없음 | 이유·대기 상태를 알리고 한도 회복 및 현재 실행 조건을 재확인한 뒤 같은 모델·추론 설정으로 자동 재개. 대기 중 취소 가능 |

둘째 상황은 첫 처리 시작 전 무료 사용분 0이라는 4-A를 유지한다. 이미 로컬 OCR 등 첫 처리를 시작한 뒤 번역 한도에 걸린 경우는 시작한 무료 사용분을 복구하지 않는 기존 규칙을 따른다. 공급사 무료 요청 한도와 사용자 무료 체험 10회분을 섞지 않으며 모델·추론 수준 변경이나 유료 자동 전환을 하지 않는다. 첫 처리 전 자동 대기·재개 방향은 확정됐고 대기 만료·최대 시간·확인 간격·일괄 작업 재개 순서는 미정이다.

실제 응답·대조 JSON은 실행·작성 당시 상태를 보존한다. 대조 요약의 선택 대기 문구는 당시 상태이며 최신 업무 결정은 이 절과 도메인 스토리 51절을 따른다. 이번 선택 반영을 새 API 실행이나 자동 재개 기능의 구현·실행 검증으로 취급하지 않는다.

### 7.6 남은 핵심 작업의 순서

1. **테스트 범위와 공급사 한도 이야기 — 선택 완료.** 현재 테스트 계정만 무료로 유지하며 첫 처리 전 한도 제한에는 이유 안내·대기·같은 설정 재개를 적용하는 업무 방향을 정했다. 출시 공급사·요금 방식은 전체 공정·원가 자료를 보고 추후 선택한다.
2. **품질을 충족하는 OCR·인페인팅·식자 경로와 운영 환경을 정한다.** 현재 로컬 OCR의 오류를 원인별로 검증하고, 선정한 공정으로 대표 만화 자료의 처리량·시간·메모리·전체 결과를 측정한다. 실제 자료의 외부 전송은 범위를 확인한 뒤 진행한다.
3. **전체 공정의 단가와 실행 상한을 만든다.** 서버·저장·전송·준비·유휴 시간·공통비의 실제 입력을 채우고, 동시 요청·실패·취소·재시도를 포함한 전체 상한을 검증한다. 단일 평균 실행 시간으로 상한을 확정하지 않는다.
4. **결제 조건·목표 수익·할인 조건을 근거로 USD 상품가와 내부 환산을 선택한다.** 2,500 / 6,000 / 15,000크레딧의 가격·마진·환산율을 지금 임의로 정하지 않는다. 결제 후보를 선택하면 계정별 정산 조건을 확인한다.
5. **갱신 주기·예외 수치를 선택하고 구현·운영 검증으로 넘긴다.** 연구용 가격 추출과 동시 여력 검증을 제품에서 구현했다는 의미로 확대하지 않는다. 무료 계정 조건에서 유료 청구서 생성은 요구하지 않는다.
