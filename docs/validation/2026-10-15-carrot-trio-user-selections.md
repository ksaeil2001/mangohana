# 유지·변경 선택표

당근망가와 현재 Trio 전체 기능 비교의 사용자 선택표다. **D01~D33 전체 33개 항목 확정·미선택 0개**다. D01~D21은 사용자가 직접 선택했고, D22~D33은 2026-10-15 사용자가 남은 선택을 추천에 위임하여 아래와 같이 채택했다. 권고·결정 근거·구현 및 검증 상태는 구분한다. [비교 보고서](2026-10-15-carrot-trio-comparison.md)에 코드 근거·차이·이유·선택한 범위의 완료 조건이 있다.

유지: 현재 Trio 방식 보존. 개선: 기존 방식의 공통 처리 보완. 교체: 해당 방식 교체 검토. 추가: 없는 기능 도입. 보류: 이번 완성 범위에서 제외/나중 결정. 미선택: 아직 결정하지 않음.

D01~D21의 직접 선택은 보존한다. 사용자의 최신 요청인 「앞으로 모든 선택은 너의 추천으로 진행…선택표의 선택을 최선의 방향으로 끝낼 때까지 계속」에 따라 D22~D33의 추천 선택을 위임받아 확정했다. 이번 작업은 선택표 완성까지이며 제품 코드 수정·실제 서비스 실행·계정/결제 변경·Git/CI 외부 연결·배포 승인으로 확대하지 않는다. 선택 변경을 원하면 D번호와 범위를 지정할 수 있다.

선택은 완료했다. 다음 단계에서 선택한 항목의 성공 기준·변경 파일·선행 조건·구현 순서·검증·되돌리기를 구체화한다. D23은 평가 방향, D27은 후속 Git·CI 연결 방향을 정한 것이며 특정 하드웨어·모델 채택이나 외부 실행은 승인하지 않았다. 실제 제품·새 만화 품질은 미검증이며 제품 코드는 수정하지 않는다.
