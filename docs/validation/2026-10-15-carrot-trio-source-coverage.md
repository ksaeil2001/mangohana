# 전체 공개 파일 확인 범위와 근거 수준

분석일: 2026-10-15. 작업 유형: 원인 분석·비교 자료 작성. 제품 실행·제품 코드 변경은 하지 않았다.

CarrotMangaTranslator v3.3.7의 커밋 `721e709d3706f15ed1ef62270460d4b8ab5d5312`에서 `git ls-files`로 추적 파일 **6,118개**를 확인했다. 그중 UTF-8 텍스트 5,841개는 본문을 읽어 행 수·선언·정적 import를 색인했고, 277개 자산은 경로·크기·해시와 종류를 확인했다. 텍스트의 합계는 1,584,794행이다. 원본 공개 저장소의 코드·모델·테스트를 실행하거나 의존성을 설치하지 않았다.

이 수치는 전체 범위의 정적 조사 목록이다. **각 코드 행의 정확성이나 모든 화면·분기의 실행·보안·품질을 검증했다는 뜻은 아니다.** 핵심 제품 경로는 별도로 호출 관계·입출력·정책·관련 테스트를 상세 검토하고, 보조·학습·패키징 모듈은 기능군에 연결했다. 바이너리/글꼴/이미지 내용, 다운로드되는 모델 가중치, vendor 의존성의 모든 수학적 내부 동작과 외부 API 내부는 이번 실행·품질 검증 범위 밖이다.

전체 CSV에는 각 파일의 경로·바이트 수·SHA-256·텍스트/자산·행 수·기능군·검토 방식·보고서 연결이 있다. 기본 정적 색인과 핵심 경로 상세 검토를 같은 완료 표시로 합치지 않는다. 모델·외부 서비스의 미확인 항목은 비교 보고서에 별도로 적는다.

Trio의 기준점은 웹 프로젝트의 기존 파일 342개와 Electron의 소스·테스트·스크립트 및 주요 루트 파일 440개, 합계 782개의 변경 전 SHA-256이다. 웹은 Git 저장소가 아니므로 파일별 해시를 기준으로 한다. Electron의 Git HEAD는 `2a754df6feb5b99299267565b1953b08a687293f`이며 기존 dirty 변경을 포함한 현재 파일이 분석 대상이다. HEAD만으로 현재 사용자 작업을 표현하지 않는다.

보고서의 '구현 확인'은 해당 코드 경로가 존재하고 연결을 읽어 확인한 의미다. '관련 테스트 존재'는 검사 소스가 있다는 의미다. 기존 실행 기록과 이번 새 실행은 다르다. 이번 제품·모델·테스트·외부 처리 API 실행은 모두 `NOT RUN`이며, 속도·원가·두 제품의 품질 우위·새 만화 자동 적용은 미검증이다.
