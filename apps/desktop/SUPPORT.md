# Trio 지원 정책

> **v0.1.4 상태:** 운영 채널이 활성화되기 전까지 공개 stable 배포는 차단됩니다.

## 운영 주체

Trio의 운영 주체는 개인 개발자 **김세일**이며 대한민국에 있습니다. 우편 주소,
사업자 등록 정보, 전화번호, 개인정보 보호 책임자 이름과 이메일 주소는 아직
제공되지 않았습니다. 주소나 연락처를 추측해 채우지 않습니다.

## 문의 채널

개인정보·일반 지원을 함께 받을 전용 이메일은 release owner가 개설·제공한 뒤에
이 문서와 개인정보 처리 방침에 게시합니다. 현재 전용 이메일은 **미정이며
비활성**입니다. 활성화 전에는 이메일 주소를 추측하거나 임시 주소를 사용하지
않습니다.

민감하지 않은 일반 버그는 향후 공개 delivery 저장소의 Issues에서 받습니다:

<https://github.com/ksaeil2001/trio-releases/issues>

이 저장소와 Issues는 아직 생성되지 않았으며 활성화되지 않았습니다. 활성화 전에는 이 URL을
지원 채널로 간주하지 말고, stable 공개를 진행하지 않습니다.

## 지원 범위와 응답 기준

- 일반 지원은 **best-effort**로 제공합니다.
- 전용 개인정보·보안 문의 채널이 활성화된 뒤에는 한국 영업일 기준 **5영업일
  이내 최초 확인**을 목표로 합니다.
- 해결 기한, 수정 릴리스, 가용성 또는 SLA를 보장하지 않습니다.
- 지원 범위는 설치·기본 프로젝트 저장·복구·업데이트 사용법과 재현 가능한
  제품 결함 안내입니다. 실제 원고의 번역 품질, 외부 AI 제공사의 정책·가용성,
  사용자 환경의 파일 복구를 보장하지 않습니다.

## 제출하지 말아야 할 정보

공개 Issue나 지원 요청에 실제 원고·이미지·`.ctp` 프로젝트·`-assets` 폴더,
API key, password, token, private key, 전체 로컬 경로, 미삭제 raw log 또는
가리지 않은 스크린샷을 첨부하지 마세요. 재현에는 합성 프로젝트와 민감정보를
제거한 오류 메시지·앱 버전·운영체제 정보만 사용하세요.

보안 취약점이나 공개하면 안 되는 개인정보는 공개 Issue에 쓰지 마세요.
[SECURITY.md](SECURITY.md)의 비공개 신고 절차를 사용해야 하지만, 해당 채널도
공개 저장소와 기능이 활성화된 뒤에만 사용할 수 있습니다.

## 현재 릴리스 판정

전용 이메일, 공개 delivery 저장소와 Issues가 실제로 활성화되고 법률 검토가
끝나기 전까지 Gate 8과 v0.1.4 stable은 `BLOCKED`입니다. 이 문서는 연락처를
제공하거나 법률 검토가 완료되었다고 주장하지 않습니다.
