# Domain docs

이 저장소는 단일 도메인 문맥으로 다룬다. 프로젝트와 UI 용어는 루트 `GLOSSARY.md`, 되돌리기 어렵고 맥락이 필요한 설계 결정은 `docs/adr/`에 기록한다.

## 필요한 문서만 읽기

- 현재 작업 경로의 `AGENTS.md` 계층을 먼저 따른다.
- 용어를 확인할 때 `GLOSSARY.md`의 관련 항목을 읽는다.
- 해당 영역의 결정이 필요하면 `docs/adr/`의 관련 기록만 읽는다.
- 현재 설계는 `docs/superpowers/specs/`, 기존 계획은 `docs/superpowers/plans/`에서 작업에 필요한 문서를 찾는다. 기존 계약과 현재 코드의 중요한 불일치는 사용자에게 알린다.

파일이 없으면 그 자체를 오류로 취급하지 않고 진행한다. 합의된 새 용어가 생길 때 용어집을 갱신하고, 중요한 결정의 기록이 실제로 필요할 때 ADR을 만든다. 이 설정을 이유로 빈 문서나 전체 문서 읽기를 요구하지 않는다.

## 기록과 충돌

용어집에는 개념의 간결한 정의만 기록한다. 구현 세부, 진행 상태, 테스트 개수와 설계 초안을 넣지 않는다. 코드나 스킬의 편의를 위해 사용자와 합의된 데이터·보안·승인 계약을 바꾸지 않는다. 기존 결정과 새 제안이 충돌하면 차이와 영향을 먼저 제시한다.
