# Triage labels

스킬의 다섯 분류를 아래 라벨에 대응시킨다. 매핑과 GitHub에 실제 라벨이 존재하는지는 별도로 확인한다.

| 스킬의 분류 | GitHub 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 관리자가 내용을 판단해야 함 |
| `needs-info` | `needs-info` | 판단에 필요한 정보가 부족함 |
| `ready-for-agent` | `ready-for-agent` | 범위와 완료 조건이 정해져 에이전트가 수행 가능함 |
| `ready-for-human` | `ready-for-human` | 사람이 수행해야 함 |
| `wontfix` | `wontfix` | 진행하지 않기로 결정함 |

기존 라벨을 다른 이름으로 사용한다면 사용자가 선택한 실제 이름으로 이 매핑만 수정한다. 라벨 생성이나 기존 이슈의 라벨 변경은 승인된 범위에서 수행한다.
