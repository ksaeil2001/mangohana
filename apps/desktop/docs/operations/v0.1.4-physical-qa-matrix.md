# Trio v0.1.4 실장비 QA 매트릭스

> 2026-09-17 범위 갱신: 이 문서의 macOS 항목은 **non-MVP / future scope**이며 현재 MVP 지원이나 Release Gate 요구가 아닙니다. Linux 범위는 변경하지 않습니다. [현재 플랫폼 정책](mvp-platform-scope.md)을 우선합니다.
> 이전 시점의 실행 결과와 gate 상태는 역사적 기록이며 현재 후보 판정은 [최신 Release Gate 보고서](../release/2026-09-17-mvp-release-gate.md)를 따릅니다.

> **기록 원칙:** 결과는 `PASS | FAIL | BLOCKED | NOT RUN` 중 하나만 사용한다.
> 자동 단위 테스트·CI startup smoke·설치 파일 생성만으로 실장비 PASS를 만들지
> 않는다. 현재 이 매트릭스의 외부 장비 시나리오는 수행 전이므로 `NOT RUN` 또는
> 전제 조건 부재 시 `BLOCKED`이다.

## 공통 준비와 증거 경계

- Windows 10/11 x64 clean VM 또는 **실제 장비**를 일반 권한과 관리자 권한으로 나누어
  기록한다. macOS는 Intel x64, Linux는 Ubuntu LTS x64를 사용한다.
- 합성 프로젝트만 사용한다. 실제 원고·이미지·`.ctp`·API key·password·token·전체
  경로·원본 로그를 공개 증거에 넣지 않는다.
- 각 행에 OS/build, 권한, DPI, artifact 이름과 SHA-256 앞 12자리, redacted 증거
  ID, 관찰과 후속 조치를 기록한다.
- `PASS`는 해당 장비에서 절차 전체와 보존 결과를 관찰한 경우에만 기록한다.

## 업데이트 전환

상세 절차와 WU-01~WU-08 결과표는
[`windows-update-transition-qa.md`](windows-update-transition-qa.md)에 둔다. 전환
baseline은 실제 과거 artifact와 bit-identical하지 않은
`0.1.3-transition.1`이며, v0.1.3 source에서 재빌드한 signed QA baseline이다.

| ID | 확인 범위 | 기본 상태 | 필요한 증거 |
| --- | --- | --- | --- |
| WU-01 | stable에 업데이트 없음 | NOT RUN | sanitized network/status |
| WU-02 | signed transition → signed `0.1.4-preview.1` 정상 확인·다운로드·명시적 재시작 | NOT RUN | 상태 전환·재열기 |
| WU-03 | update check 네트워크 실패·복구·재시도 | NOT RUN | 네트워크 조건과 UI |
| WU-04 | download 중단·손상 installer 거부 | NOT RUN | error/retry와 파일 보존 |
| WU-05 | 설치 전 종료·재실행 | NOT RUN | 명시적 설치 경계 |

sanitized network evidence를 기록한다.

## 결과 판정

각 행의 기본 상태를 실제 증거 없이 `PASS`로 변경하지 않는다. 한 행이라도
`FAIL`이면 원인·재현 절차·보존 결과를 기록하고, 장비·credential·연락 채널이
없어 시작하지 못한 경우에는 `BLOCKED`로 남긴다. 모든 필요한 행이 PASS가 되기
전까지 Gate 3, 4, 9와 stable은 No-Go다.
