이번 묶음은 major를 바꾸지 않고, 현재 저장소의 직접 개발 의존성만 npm으로 갱신했다.

| 패키지 | resolved |

`electron`과 `jsdom`이 공유하는 root `undici`는 `7.29.0`이다. `electron-builder`의 native rebuild 경로에는 `node-gyp@12.4.0`이 선언한 `undici@^6.25.0`에 맞춰 `node_modules/node-gyp/node_modules/undici@6.28.0`이 별도로 존재한다. 전역 override는 사용하지 않으며, 이 정확한 nested 경로만 build-only lower-major 경계로 허용한다.

따라서 현재 lockfile에서 ID, 경로, shipped/build-only 분류, 완화책과 30일 만료일을 기록해야 할 잔여 npm advisory는 없다. 아래의 nested `undici@6.28.0`은 audit가 보고한 advisory exception이 아니라, `node-gyp`의 선언된 semver 범위를 보존한 build-only compatibility 경계다. `npm audit fix --force`는 실행하지 않았다.

## build-only override 확인

`node-gyp@12.4.0`의 `undici@^6.25.0` 요구는 `6.28.0`으로 충족되고, Electron/jsdom의 root 경로는 `7.29.0` floor를 충족한다. 계약 테스트는 `node_modules/node-gyp/node_modules/undici` 하나만 `>=6.25.0 <7.0.0` 및 `dev=true`로 허용하며, 다른 lower-major 경로는 실패시킨다. `npm ci`, typecheck, build와 실제 지원 플랫폼 native rebuild/package smoke에서 이 graph를 재검증해야 하며, 해당 검증이 실패하면 stable은 No-Go다.
