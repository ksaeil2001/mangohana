# Trio v0.1.4

> **배포 상태: 미공개(No-Go)**

이 문서는 private source candidate bundle에 복사할 수 있는 릴리스 노트 초안입니다. `v0.1.4` stable Git tag, GitHub Release 또는 공개 다운로드 자산은 아직 생성되지 않았습니다.

## 이번 후보의 범위

- Windows x64 NSIS를 대상으로 하는 MVP 후보. macOS는 MVP 제외이며 기존 Linux AppImage 범위는 변경 없음
- 원본·cleaned·typeset export, 승인 기반 작업 큐, `.ctp` 저장·복구와 revision 보호
- Windows signed package와 Pretendard production resource가 검증된 경우에만 typeset stable export 허용
- Linux는 수동 AppImage 다운로드만 제공하며 자동 업데이트는 비활성화

## 공개 전 남은 조건

stable 공개 전 아래 외부 증거와 운영 결정을 모두 확인해야 합니다.

- Windows SSL.com eSigner CKA 계정·publisher certificate·timestamp 검증 및 지원 Windows runner 결과
- committed Production Pretendard CMS/allowlist를 사용한 최종 패키지 hash·renderer glyph evidence (공개 signer material은 준비 완료)
- 설치본의 Windows 저장·복구·업데이트·DPI QA와 기존 Linux 실장비 QA
- 승인된 Trio 아이콘 원본 및 Windows `.ico`, 기존 Linux PNG 계층
- 개인정보 처리 방침·LICENSE/EULA의 법률 검토, privacy/support 이메일, 운영 주체와 보안 신고 채널 확정
- candidate source SHA, canonical `release-evidence.json` digest, SHA-256 checksums, CycloneDX SBOM, 제3자 고지와 provenance의 최종 일치

이 조건 중 하나라도 미완료이면 후보는 private CI artifact로만 보관하고 stable로 승격하지 않습니다. 실제 원고, API key, password, token, signing 원본 로그와 개인 경로는 릴리스 자산에 포함하지 않습니다.

## 업데이트 채널

stable Windows feed는 서명된 public delivery repository가 준비된 뒤에만 활성화됩니다. preview/dev/transition 후보는 stable 사용자의 자동 업데이트 대상이 아니며, Linux stable은 v0.1.4에서 자동 업데이트를 사용하지 않습니다.

## 지원 정책

일반 지원은 best-effort입니다. privacy/security 문의에는 5영업일 이내 최초 확인을 목표로 하며 해결 기한은 보장하지 않습니다. 실제 문의 이메일과 공개 지원 문서는 외부 운영 정보가 확정된 뒤에 이 초안에 반영합니다.
