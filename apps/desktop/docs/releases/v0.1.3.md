# Trio v0.1.3

> 2026-09-17 범위 갱신: 이 문서의 macOS 항목은 **non-MVP / future scope**이며 현재 MVP 지원이나 Release Gate 요구가 아닙니다. Linux 범위는 변경하지 않습니다. [현재 플랫폼 정책](../operations/mvp-platform-scope.md)을 우선합니다.
> 이전 시점의 실행 결과와 gate 상태는 역사적 기록이며 현재 후보 판정은 [최신 Release Gate 보고서](../release/2026-09-17-mvp-release-gate.md)를 따릅니다.

**공개일:** 2026-08-18

## 주요 변경

- 작업대에서 업데이트 확인, 다운로드 진행률, 설치 준비, 오류, 재시도 및 Release 열기 행동을 확인할 수 있는 상태 제어 UI를 추가했습니다.
- 메인·프리로드·렌더러 사이에 업데이트 상태 조회, 확인, 다운로드, 설치 및 Release 열기 IPC 계약을 연결했습니다.
- 유효한 CMS 분리 서명을 검증할 수 있도록 PKIJS의 Node WebCrypto 엔진 초기화를 보완했습니다.
- CMS fixture를 공개 키·인증서·서명만 남기는 재현 가능한 OpenSSL 스크립트로 갱신했습니다.

## 수정

- CMS 검증이 유효한 서명을 `CMS_SIGNATURE_INVALID`로 분류하던 문제를 수정했습니다. 이제 서명자 미신뢰, 지원하지 않는 알고리즘, 잘못된 인증서 오류를 구분합니다.
- Linux CI에서 Windows 드라이브 경로를 절대 경로로 인식하지 못해 환경 준비 테스트가 실패하던 문제를 수정했습니다.
- Windows 파일 잠금에 의존하는 원자적 rename 실패 테스트를 Windows에서만 실행하도록 분리해 Linux에서의 잘못된 실패를 제거했습니다.

## 배포 자산

- Windows x64 NSIS 설치 파일
- macOS Intel x64 DMG 및 ZIP
- Linux x64 AppImage
- Windows·macOS·Linux 업데이트 메타데이터

## 알려진 제한

- `빠른 번역`과 `정확 번역`은 현재 프로젝트 의도를 저장하는 모드이며, 작품 전체 자동 OCR·번역·합성 파이프라인은 아직 제공하지 않습니다.
- macOS 자동 업데이트는 Apple 코드 서명·공증 구성이 완료되기 전까지 제공되지 않습니다. 최신 DMG 또는 ZIP을 수동으로 설치해야 합니다.
- API 기반 OCR·인페인팅은 사용자가 보유한 Gemini 또는 OpenAI 자격 증명과 해당 제공사의 이용 조건을 따릅니다.
