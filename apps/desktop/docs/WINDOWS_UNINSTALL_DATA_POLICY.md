# Windows 제거 시 데이터 처리 정책

Trio의 Windows 설치 파일은 NSIS 제거 프로그램을 사용한다. 이제 `deleteAppDataOnUninstall`을 활성화했으므로, **제어판 또는 Windows 설정에서 Trio를 제거하면 앱의 사용자 데이터 폴더도 함께 삭제**된다.

| 데이터 종류 | 제거 시 처리 | 이유 |
|---|---|---|
| 최근 프로젝트 목록 | 삭제 | 이전 프로젝트가 자동으로 다시 열리지 않게 함 |
| 마지막 작업 화면·패널·확대 상태 | 삭제 | 재설치 후 깨끗한 첫 화면으로 시작하게 함 |
| 앱 설정·암호화된 API 키 | 삭제 | 앱 데이터를 완전히 초기화함 |
| 사용자가 직접 저장한 프로젝트 파일 | 보존 | 실제 작업물을 제거 프로그램이 임의로 지우지 않음 |
| 프로젝트 파일 옆의 `-assets/images` 폴더 | 보존 | 프로젝트에 연결된 원본 이미지와 결과물을 보호함 |

프로젝트 파일과 이미지까지 제거하려면 사용자가 해당 프로젝트 파일과 같은 위치의 `프로젝트명-assets` 폴더를 직접 삭제해야 한다. 이 정책은 자동 복원 정보는 제거하면서도 사용자의 실제 작업 파일을 보호하기 위한 구분이다.
