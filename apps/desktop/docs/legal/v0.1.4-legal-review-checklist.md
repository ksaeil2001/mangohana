## 검토 시 확인할 사실

- 운영 주체는 개인 개발자 김세일, 대한민국이다. 주소·사업자 정보·DPO·이메일은
  release owner가 제공하기 전까지 문서에 임의로 쓰지 않는다.
- `.ctp`, `-assets`, recovery candidate/journal, recent state와 API key의 로컬·세션
  보관 및 uninstall 동작은 실제 코드와 QA 증거로 대조한다.
- 사용자가 선택한 Gemini/OpenAI 기능이 전체 이미지 또는 Crop, OCR·대사·번역,
  prompt/context를 외부 제공사로 보낼 수 있음을 고지한다. 제공사의 보관·학습·
  국외 이전·계정 정책은 계약과 지역에 따라 달라질 수 있으므로 보장 문구를
  넣지 않는다.
- 법률 검토 전에는 상용 판매·조직 배포·stable 공개를 승인하지 않는다.
- 라이선스의 실질적인 조항을 검토 완료처럼 고치지 않는다. 검토자가 요청한
  변경만 별도 기록과 함께 반영한다.
