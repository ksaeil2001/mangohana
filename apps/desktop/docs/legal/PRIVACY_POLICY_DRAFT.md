# Trio 개인정보 처리 방침 초안

> **초안 — 법률 검토 후 공개·적용 필요**
>
> 이 문서는 Trio v0.1.4의 알려진 동작을 기준으로 작성한 개인정보 처리 방침 초안입니다. 실제 유료 판매, 조직 도입, 계정·결제·분석·클라우드 동기화 기능의 제공 또는 특정 국가 사용자 대상 배포 전에, 관할 법률에 맞추어 자격 있는 법률 전문가의 검토를 받고 운영 주체·연락처·처리 근거를 확정해야 합니다.

**초안 작성일:** 2026-08-18  
**대상 버전:** Trio v0.1.4

## 1. 적용 범위와 운영 주체

이 초안은 데스크톱 애플리케이션 Trio가 로컬 기기에서 프로젝트를 생성·편집하고, 사용자가 선택적으로 외부 AI 서비스에 연결할 때의 데이터 흐름을 설명합니다.

현재 운영 주체는 **개인 개발자 김세일**이며, 관할은 **대한민국**으로 정했습니다. 등록 주소, 개인정보 보호 책임자, 개인정보 문의 채널, 일반 지원 채널 및 보안 신고 채널은 아직 확정되지 않았습니다. 전용 개인정보·지원 이메일은 release owner가 제공하기 전까지 **미정·비활성**이며, 주소나 연락처를 임의로 만들지 않습니다. 이 정보는 유료 판매 또는 조직 배포 전에 확정해 이 문서에 채워야 합니다.

| 필수 공개 항목 | 상용 배포 전 확정할 내용 |
| --- | --- |
| 개인정보처리자 | 개인 개발자 김세일, 대한민국; 등록 주소 및 사업자 정보는 미정 |
| 연락처 | 개인정보·일반 지원용 전용 이메일 또는 웹 양식은 미정·비활성 |
| 법적 근거 | 지역별 동의, 계약 이행, 정당한 이익 등 처리 근거 |
| 감독기관 안내 | 적용 법률에서 요구하는 불만 제기·감독기관 정보 |

## 2. 처리하는 데이터

Trio는 기본적으로 사용자가 선택한 로컬 파일과 프로젝트 데이터를 사용자의 기기에 보관합니다.

| 데이터 범주 | 예시 | 기본 보관 위치·목적 |
| --- | --- | --- |
| 프로젝트 데이터 | `.ctp` 프로젝트, 페이지 순서, OCR 후보, 화자, 번역문, 메모, 검토 상태 | 사용자가 선택한 로컬 프로젝트 경로에서 작업을 저장·복원하기 위해 사용 |
| 이미지 자산 | 원본의 작업용 사본, 인페인팅 결과 | 프로젝트와 연계된 `-assets/images` 폴더에서 페이지 검토·인페인팅 결과 보관에 사용 |
| 복구 상태 | recovery journal, backup/candidate와 recent state | 저장 실패·복구·최근 작업 재개를 위해 로컬 앱 데이터에 보관될 수 있음 |
| API 키 상태 | Gemini 키의 암호화 저장 상태 또는 해당 실행 세션 키 | Gemini 키는 OS 계정에 연결된 Electron `safeStorage` 암호화 저장을 시도하며, 불가능할 때 평문 파일로 저장하지 않음 |
| 진단·지원 정보 | 사용자가 GitHub Issue 또는 지원 채널에 자발적으로 제공한 버전, 운영체제, 오류 설명 | 문제 재현·지원에 사용되며, 공개 Issue에 작성한 내용은 공개될 수 있음 |

OpenAI 인페인팅 키는 현재 사용자가 구성한 `OPENAI_API_KEY` 환경 변수에서 읽습니다. Trio는 이 키를 프로젝트 파일에 기록하지 않습니다.

## 3. 외부 AI 제공사 전송

사용자가 Gemini OCR·검증·Crop 재OCR·Gemini 인페인팅 또는 OpenAI 인페인팅을 직접 실행할 때, 해당 기능에 필요한 데이터가 선택한 외부 AI 제공사로 전송될 수 있습니다. 데이터에는 만화 **전체 이미지 또는 일부 Crop**, 사용자가 입력한 지시문(`prompt`), OCR 대상 텍스트·대사·번역문 및 번역 작업에 관련된 문맥(`context`)이 포함될 수 있습니다.

Trio는 외부 AI 제공사의 데이터 보관, 모델 학습 사용, 지역 간 이전, 가격, 가용성 또는 계정 정책을 통제하지 않습니다. 제공사의 보관·학습·국외 이전 조건은 사용자의 계약·계정·지역에 따라 달라질 수 있으며 Trio가 특정 결과를 보장하지 않습니다. 사용자는 해당 제공사의 약관·개인정보 처리 방침을 확인하고, 원고·개인정보·기밀 정보를 전송할 권한과 필요한 동의를 확보해야 합니다.

## 4. 수집하지 않는 데이터와 향후 변경

v0.1.4 기준 Trio는 자체 계정, 결제, 고객 데이터베이스, 클라우드 동기화 또는 제품 분석 서비스를 제공하는 것을 목표로 하지 않습니다. 따라서 Trio 운영자가 운영하는 중앙 서버로 프로젝트 파일이나 API 키를 정기 전송하도록 설계된 기능은 이 버전에 포함되지 않습니다.

향후 계정, 결제, 오류 분석, 사용량 분석, 푸시 알림, 원격 백업, 협업 또는 고객 지원 플랫폼을 추가하는 경우에는 해당 기능 출시 전에 이 문서를 갱신하고, 필요한 고지·동의·처리자 계약·보안 조치를 마련해야 합니다.

## 5. 보관, 삭제 및 사용자의 선택

프로젝트와 이미지 자산은 사용자의 로컬 저장 위치에 남아 있습니다. 사용자는 `.ctp` 파일과 연결된 `-assets` 폴더를 삭제해 로컬 프로젝트 데이터를 제거할 수 있습니다. recovery journal·backup·candidate·recent state는 앱의 복구·최근 작업 데이터로 별도 관리될 수 있으므로, 사용자는 앱의 복구 UI와 운영체제 저장소를 확인해야 합니다. 프로젝트를 백업하거나 다른 기기로 옮길 때는 `.ctp`와 `-assets`를 함께 관리해야 합니다.

사용자는 앱 설정에서 저장된 Gemini 키를 제거하거나, 환경 변수에서 OpenAI 키를 삭제할 수 있습니다. API 제공사 계정에 이미 전송된 콘텐츠 및 사용 기록의 보관·삭제 요청은 해당 제공사의 절차를 따라야 합니다.

Windows NSIS uninstall은 앱 설정, Electron `safeStorage`에 저장된 API key 상태와
recent state처럼 앱 데이터에 속한 항목을 제거하도록 구성되어 있습니다. 사용자가
별도로 저장한 `.ctp` 파일과 연결된 `-assets` 폴더는 앱 데이터와 다른 사용자 파일이므로
uninstall이 임의로 삭제해서는 안 됩니다. 이 분리는 실제 설치본 QA에서 확인해야 하며,
현재 해당 실장비 증거는 아직 없습니다.

## 6. 보안 조치와 한계

Trio는 원본 이미지를 직접 덮어쓰지 않고 작업용 자산 사본을 사용합니다. Gemini 키는 가능할 때 OS의 `safeStorage`를 이용해 암호화 저장하며, 프로젝트 파일에 API 키나 암호문을 넣지 않습니다. 시크릿 프로젝트는 AES-256-GCM 기반 암호화 방식을 사용합니다.

어떤 시스템도 완전한 보안을 보장할 수 없습니다. 사용자는 기기 암호화, OS 계정 보호, 백업 관리, API 키 회전 및 최소 권한 원칙을 적용해야 합니다. API 키, 원고 원본, 개인 식별 정보 또는 비밀 정보를 GitHub Issue·스크린샷·공개 지원 요청에 게시하지 마세요.

## 7. 아동·민감 정보·국제 전송

Trio는 아동을 대상으로 설계되지 않았습니다. 사용자는 특별 범주의 개인정보, 미성년자 정보, 의료·금융·법률 기록 또는 제3자의 기밀 콘텐츠를 외부 AI 서비스로 전송하기 전에 적용 법률과 조직 정책을 검토해야 합니다.

외부 AI 제공사를 이용하면 데이터가 사용자의 국가 밖에서 처리될 수 있습니다. 이러한 국제 전송의 법적 적합성, 사용자 동의 및 계약상 보호 조치는 사용자의 이용 환경과 선택한 제공사에 따라 달라집니다.

## 8. 문의와 개정

상용 배포 전에는 운영 주체의 공식 개인정보 문의 채널과 보안 취약점 신고 채널을 이 절에 게시해야 합니다. 현재 전용 이메일과 공개 delivery 저장소의 private reporting은 **미정·비활성**이며, 활성화 전까지 GitHub Issues는 민감한 개인정보 또는 보안 정보 제출 채널이 아닙니다. 일반 지원은 best-effort이고, 채널이 활성화된 뒤 개인정보·보안 문의에 대해서만 한국 영업일 기준 5영업일 이내 최초 확인을 목표로 하며 해결 기한이나 SLA를 보장하지 않습니다.

기능·법률·운영 방식이 변경되면 이 방침의 날짜와 변경 내용을 갱신해야 합니다. 중요한 변경은 적용 전에 적절한 방식으로 고지합니다.
